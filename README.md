## 🔒 Sécurité & Intégrité

- **Architecture non-custodial :** Vos clés privées et phrases mnémoniques (BIP-39) ne quittent jamais votre appareil.
- **Stockage chiffré :** Chiffrement local sécurisé (AES-256-GCM / SecureStore) protégé par code PIN et authentification biométrique.
